# Six-month maintenance plan

These are planned responsibilities, not claims of work already completed.

| Period | Maintainer work | Verifiable output |
| --- | --- | --- |
| Month 1 | Triage reproducible text-layer failures and harden cross-platform delivery | Linked reproducer, passing core CI, recorded engine/config |
| Month 2 | Add focused cases for diacritics and additional mixed-direction patterns | Original licensed sources, reviewed renderings, positive/mutation controls |
| Month 3 | Test selected extractor upgrades against pinned baselines | Raw runs, version comparison reports, explicit regression decisions |
| Month 4 | Review authorized external fixture contributions when available | Provenance checks and minimal independently specified expectations |
| Month 5 | Improve contributor instructions and package/install portability | Updated guides and clean installed-wheel checks |
| Month 6 | Review compatibility findings and prepare the next scoped release | Changelog, measured results, documented remaining limitations |

Use Codex for implementation review, test design, failure triage and documentation.
Keep deterministic ground truth and evaluation independent of AI-generated output.
Review contributions and issues when they arrive; do not create artificial activity
to imply community participation. Do not promise upstream adoption or performance.
